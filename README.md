## ✨ Fitur Utama
- **Desain Modern & Responsif:** Menggunakan pendekatan *Mobile-First Design* dengan Tailwind CSS v4, sehingga nyaman dilihat di HP maupun monitor PC.
- **Komponen Modular:** Dibangun menggunakan Vue.js dengan memisahkan halaman menjadi komponen-komponen kecil (*Navbar, Hero, About, Skills, Projects, Contact*) agar kode mudah dikelola.
- **Daftar Proyek Dinamis:** Menampilkan proyek-proyek menggunakan fitur *reactivity* dan looping (`v-for`) dari Vue.js.

---

## 🛠️ Tech Stack & Alat yang Digunakan

### Frontend
- **Framework Utama:** Vue.js 3 (`<script setup>` syntax)
- **Styling & Desain:** Tailwind CSS v4
- **Build Tool / Bundler:** Vite

### Lingkungan Pengembangan (Development Environment)
- **OS:** Ubuntu 24.04.4 LTS / Windows 11 (Dual Boot)
- **Code Editor:** Visual Studio Code
- **Runtime:** Node.js (v22.x)

---

## 📂 Struktur Komponen Proyek
Kodenya dipecah secara modular di dalam folder `src/components/`:
- `Navbar.vue` - Menu navigasi atas dengan efek *sticky blur*.
- `Hero.vue` - Bagian pembuka, salam kenal, dan foto profil.
- `About.vue` - Latar belakang singkat sebagai mahasiswa Sistem Informasi.
- `Skills.vue` - Daftar teknologi dan *tools* yang dikuasai.
- `Projects.vue` - Grid kartu (*cards*) yang berisi detail proyek pemrograman.
- `Contact.vue` - Bagian kaki (*footer*) dan hak cipta.
